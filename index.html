How to Grant File Access / Request File

Follow these steps to grant or request file access via email:

1

Open your email

Open your preferred email provider, such as Gmail or Outlook.

2

Compose a new message

Click the button to create or write a new email.

3

Add the recipient

In the “To” field, type: support.hl8006 (or support.hl8006@gmail.com).

4

Write the subject line

Make the subject clear, such as “File Access Granted” or “Access to File”.

5

Include the file details

In the main body of the email, paste the link to your file or attach the file directly. Be sure to mention that you are granting access to it.

6

Send the email

Click send to deliver your access request to the support team.
